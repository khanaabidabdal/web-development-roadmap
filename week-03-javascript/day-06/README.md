# Employee Payroll Management System

The following project is purely built using JavaScript for the calculation of the Employees Summary,Payroll Etc

## The following things can be caluculated using this project :

1. Display all employees.

2. Find an employee by ID.

3. Calculate an employee's gross and net salary.

4. List active employees.

5. Calculate total payroll for active employees.

6. Filter employees by department.

7. Generate a payroll summary.

## Working

Create a two seprates files one Index.html and other app.js. The index.html will serve the frontend while the app.js contains the logic and you can see the result by inspecting the index.html page in console. The html file load the the JavaScript and that results appear in the browser's Developer Tools console, not directly on the page.
